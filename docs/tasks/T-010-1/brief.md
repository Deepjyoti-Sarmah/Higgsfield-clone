## The change
1. **`schemas/sequence_jobs.py`:** the models exactly as in design.md, including the comment on `transition_in`.
2. **`schemas/credits.py`:** add `LedgerKind`, `LedgerEntryResponse` and `LedgerListResponse`.
3. **`schemas/jobs.py`:**
   - `JobKind` gains `"sequence"`.
   - Add `LibraryImageResponse`.
   - `LibraryItemResponse` gains `images: list[LibraryImageResponse] = []`, `clip_count: int | None = None` and `duration_ms: int | None = None`.
   - Don't touch any other model.
4. **`schemas/uploads.py`:** widen `UploadContentType` with the three audio types. Leave `MAX_UPLOAD_BYTES` unchanged.
5. **`schemas/share.py`:** `PublicJobResponse` exactly as in design.md. `kind` defaults to `"video"`; `preset_slug` and `preset_name` become `str | None`.
6. **`routers/sequence_jobs.py`** (new, tag `sequence-jobs`):
   - `POST /api/v1/sequence-jobs`: status 202, `response_model=SequenceJobCreatedResponse`, `responses` for 401/402/404/422/429.
   - `GET /api/v1/sequence-jobs/{job_id}`: `response_model=SequenceJobResponse`, `responses` for 401/404.
   - Both require the current user and then `raise HTTPException(501, "Not implemented yet (T-010-3)")`.
7. **`routers/credits.py`:** add `GET /api/v1/credits/ledger` with `limit: int = Query(10, ge=1, le=50)`, `response_model=LedgerListResponse` and 401 in `responses`. It raises 501 `"Not implemented yet (T-010-4)"`.
8. **`main.py`:** include the new router next to the image-jobs router.
9. Run `scripts/export-openapi` and `npm --prefix apps/web run gen:api`.
10. **`tests/test_contract_010.py`:**
    - The three new paths exist in `app.openapi()`.
    - `SequenceJobCreateRequest` rejects 1 clip and 7 clips (422).
    - An unknown transition gets 422.
    - An authenticated POST and GET return 501.
    - `GET /credits/ledger?limit=0` gets 422.
    - `UploadContentType` accepts `audio/mpeg`.
    - `PublicJobResponse(kind` omitted`)` defaults to `video`.

    Use the fixtures the existing API tests use (see `tests/conftest.py`).
